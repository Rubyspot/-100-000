# Stone and sand relief

Normal maps (512×512 WebP) from the `@pmndrs/assets` package
(https://www.npmjs.com/package/@pmndrs/assets, version 1.7.0), which
publishes them under CC0 1.0 (see LICENSE-CC0.txt). The previews are at
https://github.com/emmelleppi/normal-maps.

- `cliff-normal.webp` (0005 in the package): an upright cliff face, used on
  the sides of the rock.
- `rough-normal.webp` (0010): rough stone, used on the tops of the rock.
- `grain-normal.webp` (0015): coarse sand and grit, used on the beaches.
